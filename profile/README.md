## 🚀 Why Cloudisy?

Cloudisy is built to empower the Bangladeshi developer community by removing the barriers of international payments and complex infrastructure.

- **⚡ Optimized for Modern Frameworks**: Native support for React, Next.js, Vite, and more.
- **🇧🇩 Localized Payments**: Seamlessly upgrade or pay-as-you-go using **bKash, Nagad, and Upay**.
- **🔒 Security by Default**: Free SSL certificates for every project.
- **🌍 Subdomain Support**: Deploy instantly with a custom `*.cloudisy.app` subdomain.
- **🛠️ Developer Experience**: Deploy via **Git** push or our powerful **CLI**.

2. **Connect**: Link your GitHub/GitLab repository.
3. **Deploy**: Push your code and we handle the rest (Build, SSL, Logs, Analytics).
